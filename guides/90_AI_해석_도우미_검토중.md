# AI 해석 도우미 (검토 중 · 아직 없는 기능)

**상태**: 이 프로그램에는 아직 **없는 기능**입니다. 앞으로 추가할 수 있는지 검토 중이며, 여기에는 그 가능성과 조건만 정리했습니다. 지금 결과 해석은 프로그램이 붙이는 **✅ 🟡 🔴 판정, ⚠️ 경고, 예상 방향 점검, 확인 체크리스트** 로 합니다.

### 어떤 기능인가
분석 결과의 **요약 숫자와 문장만** Claude 같은 AI에게 보내서, 쉬운 말로 된 해석과 다음에 확인할 일을 받는 기능입니다.

| 예: AI에게 보내는 내용 | 예: 받는 답 |
|---|---|
| "예측 대상 Component 1, 입력 감도단온도, 검증 R² 0.99, 지연 60분, 경고 없음, 예상 방향 5개 모두 예상대로" | "감도단 온도가 조성을 1시간 앞서 잘 설명합니다. 트레이 온도 제어로 조성을 관리할 수 있다는 근거입니다. DCS에 넣기 전에 다른 달 데이터로 모델 적용을 확인하세요." |
| "원료유량–감도단온도 r = 0.21, 데이터 점검: 원료유량 범위 밖 값 151개" | "정지 구간이 섞여 관계가 흐려졌을 가능성이 큽니다. 운전 조건 필터로 가동 구간만 남기고 다시 보세요." |

### 보내는 것 / 보내지 않는 것 (구현한다면)
| 보냄 | 보내지 않음 |
|---|---|
| 결과 요약 문장, R²·r 같은 결과 숫자, 경고 문구 | 운전데이터 원본, 분석데이터 원본, 파일 |
| (선택) 태그 이름 — 익명화(`T1`, `F2`) 옵션 제공 | 파일 이름, 사용자 정보 |

### 쓰려면 필요한 조건
1. **회사 정보보호 승인** — 태그 이름·설비 정보·결과가 회사 밖(AI 서비스)으로 나갑니다. 지금 이 프로그램은 외부로 아무것도 보내지 않는 것이 원칙입니다 (매뉴얼 9장).
2. **인터넷 연결** — 회사 방화벽에서 AI 서비스 주소 허용이 필요합니다. 폐쇄망 PC에서는 쓸 수 없습니다.
3. **API 키와 비용** — AI 서비스 계정과 키가 필요하며, 사용량만큼 요금이 나갑니다.
4. (대안) **사내 승인 AI** 가 있다면 그쪽으로 연결하는 방식이 더 안전합니다.

### 구현한다면 지킬 원칙
- **기본은 꺼짐.** 사용자가 켜야만 동작합니다.
- **보내기 전에 보낼 내용을 화면에 그대로 보여 주고**, 사용자가 확인해야 보냅니다.
- AI 답은 **참고 의견** 으로만 표시합니다. 프로그램의 ✅/⚠️ 판정과 공정 원리 확인이 항상 우선입니다.

### 한계 (알아둘 점)
- AI도 틀릴 수 있습니다. 특히 이 설비만의 사정(계기 위치, 제어 구조, 운전 이력)은 모릅니다.
- 데이터를 직접 보지 않고 요약만 보므로, 요약에 없는 문제(예: 점검에서 못 잡은 계기 이상)는 찾지 못합니다.
- 결론은 사람이 내립니다. AI 답을 근거로 운전 조건을 바꾸지 마세요.
