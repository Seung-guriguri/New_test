# 처음 사용할 때

**이 프로그램으로 하는 일**: 운전데이터(DCS/PI)와 분석데이터(LIMS)를 올려서, **어떤 운전 변수가 품질·성능과 관련 있는지** 찾고, 그 관계로 품질을 예측하는 식을 만듭니다.

### 기본 흐름 (5단계)
1. **데이터 올리기** — 왼쪽 사이드바 ① 운전데이터, ② 분석데이터(있으면). 분석값은 분석시간 기준으로 운전데이터 시간축에 자동으로 붙습니다 (`[분석] Component 1` 처럼 표시).
2. **데이터 품질 확인** — **트렌드 · 통계** 탭: 빈 구간, 값이 멈춘 태그(고착), 계단처럼 튄 구간이 없는지. 이상한 기간은 사이드바 **기간** 으로 빼세요.
3. **관계 찾기** — **상관분석** 탭 → **변수 쌍 순위** 에서 '변수로 거르기' 에 관심 변수(예: `[분석] Component 1`)를 고르면 관련이 큰 변수부터 나옵니다. 아래 **결과 요약** 문장을 먼저 읽으세요.
4. **관계 확인** — 후보 변수를 클릭해 **이변량 회귀**(식·그래프), **시차 상관**(몇 분 뒤 반응하는지)으로 확인합니다.
5. **예측 모델** — **소프트센서** 탭: 예측 대상 = 분석값, 입력 = 3~4단계에서 찾은 변수 3~6개. **최적 지연 자동 탐색** 을 누르고 검증 R² 를 봅니다.

### 숫자 읽는 법 (최소한)
| 값 | 뜻 |
|---|---|
| r (상관계수) | −1 ~ 1. 0.7 이상이면 강한 관계, 0.4~0.7 중간, 0.2 미만 거의 없음. + 는 같이 증가, − 는 반대로 움직임 |
| R² | 모델이 설명하는 비율. 0.9 이상 매우 좋음, 0.7 이상 좋음, 0.5 미만 부족 |
| p값 | 우연일 확률. 0.01 미만이면 우연이 아님. 단, 관계의 크기(r)가 더 중요 |

> 관계가 있다고 원인은 아닙니다. 공정 원리로 설명되는지 꼭 확인하세요. 설비별로 무엇을 비교하면 좋은지는 위 목록에서 설비를 고르세요.
