# 공정단위 (수지 · 원단위 · 안정성)

**목적**: 계기 오차·누설을 찾고(물질수지), 에너지를 얼마나 쓰는지(원단위), 운전이 언제 안정적이었는지, 무엇이 언제 바뀌었는지 봅니다.

### 준비할 데이터
| 구분 | 태그 |
|---|---|
| 물질수지 | 공정단위로 들어가는 모든 유량(원료)과 나가는 모든 유량(제품·부산물·손실) — 같은 단위로 환산할 계수 |
| 원단위 | 스팀·전력·연료 등 사용량, 생산량 |
| 안정성·이상감지 | 핵심 유량·온도·압력 5~20개 |

### 먼저 볼 것
| 무엇 | 확인할 것 | 어디서 |
|---|---|---|
| 수지 불일치 [%] | 0 근처가 정상. 계단처럼 바뀌면 계기 교정 오차, 갑자기 커지면 누설·계기 고장 | 공정단위 → 물질·에너지 수지 |
| 기간별 원단위 | 특정 날만 튀면 누설·비정상 운전, 꾸준히 오르면 설비 효율 저하 | 공정단위 → 원단위 |
| 정상상태 비율 | 안정 운전 기간만 골라 다른 분석에 쓰기 | 공정단위 → 정상상태 구간 |
| 변화점 | 운전 모드(부하·원료·설비 변경)가 바뀐 시점 | 공정단위 → 변화점 탐지 |
| T² · SPE | 평소 관계가 깨진 시점과 원인 태그 | 공정단위 → 이상감지 (PCA) |

### 분석 순서
1. **물질·에너지 수지** → 계기 신뢰성부터 확인 (다른 분석의 전제).
2. **정상상태 구간** → 안정 구간만 필터 → 상관분석·소프트센서를 안정 구간으로.
3. **변화점 탐지** → 모드별 구간 → 상관분석 **운전 구간별 비교**.
4. **이상감지 (PCA)** → 정상 기간으로 학습 후 이상 시점·원인 태그.

### 주의할 점
- 수지는 모든 흐름이 빠짐없이 들어가야 의미가 있습니다. 빠진 흐름이 있으면 일정한 불일치로 나타납니다.
- PCA 학습 구간에 이상 운전이 섞이면 이상을 못 잡습니다.
