# 열교환기

**목적**: 전열 성능(U)이 얼마나 떨어졌는지, 언제 세정해야 하는지, 성능 저하가 부하·온도 때문인지 오염(파울링) 때문인지 구분합니다.

### 준비할 데이터
| 구분 | 태그 |
|---|---|
| 필수 | 고온측 입·출구 온도, 저온측 입·출구 온도, 고온측 또는 저온측 유량 (둘 다 있으면 더 좋음) |
| 물성·사양 (직접 입력) | 양쪽 비열, (m³/h 유량이면) 밀도, 전열 면적, 청정 U(설계값), 세정 기준 파울링 저항 |
| 있으면 좋음 | 세정·정비 이력(날짜), 원료 종류·부하 |

### 먼저 볼 관계
| 관계 | 확인할 것 | 어디서 |
|---|---|---|
| U(또는 UA)의 시간 추세 | 꾸준히 떨어지면 파울링. 기울기(%/일)로 세정 시기 예측 | 설비 KPI → 열교환기 |
| 열수지 차이 | ±10% 안이어야 계기·물성값이 믿을 만함. 벗어나면 KPI부터 의심 | 설비 KPI → 열교환기 |
| U ↔ 유량(부하) | 부하가 낮으면 U도 낮게 나옴(유속 효과). 부하 때문인지 오염 때문인지 구분 | 상관분석 → 이변량 회귀 (`[HX] U` 사용) |
| U ↔ 고온측 입구 온도·원료 성상 | 특정 원료·온도에서 오염이 빨라지는지 | 운전 구간별 비교 |
| 세정 전후 U | 세정 효과와 회복 정도 | 공정단위 → 변화점 탐지 (`[HX] U`) |

### 분석 순서
1. **설비 KPI → 열교환기**: 태그·물성 연결 → U 추세·파울링 저항·열수지 확인. 설정은 **설정 파일로 저장**.
2. **트렌드**: `[HX] U` 와 원료 유량을 태그별 분리로 비교.
3. **상관분석 → 이변량 회귀**: X = 유량, Y = `[HX] U` → 부하 영향 크기 확인.
4. **변화점 탐지**: `[HX] U` → 세정·운전 변경 시점 확인.

### 주의할 점
- 상변화(응축·증발)가 있는 쪽은 현열 계산이 맞지 않습니다. 그쪽 유량은 연결하지 마세요.
- 온도 교차(고온측 출구 < 저온측 입구)가 있으면 LMTD를 계산할 수 없습니다.

> **예상 방향 점검** (상관분석 탭): **태그 이름으로 자동 채우기** 가 냉각수 유량↑ → 공정 유체 출구 온도↓, 냉각수 입구 온도↑ → 출구 온도↑, 입구 온도↑ → 같은 흐름의 출구 온도↑ 를 넣습니다. 반대로 나오면 냉각수 유량계·온도계 위치부터 확인하세요.
