# 일반 데이터 (장치와 무관)

**목적**: 실험 결과, 품질·유틸리티·판매 데이터 등 어떤 숫자 데이터든 변수 사이 관계를 찾습니다.

### 준비할 데이터
- 첫 행 헤더, 변수별 열. 시간이 없으면 사이드바 시간 컬럼에서 **(없음 · 행 순서대로)** 또는 시료번호 컬럼.
- `Yes`/`No`, `가동`/`정지` 같은 상태 컬럼은 자동으로 1/0이 되어 분석에 들어갑니다.

### 분석 순서
1. **상관분석 → 상관 행렬**: 정렬 = 비슷한 변수끼리 → 덩어리로 묶인 변수군 확인.
2. **변수 쌍 순위**: 관계 유형이 **곡선** 이면 이변량 회귀에서 2차식·로그 등을 비교.
3. **이변량 회귀 → 잔차 분석**: 잔차에 패턴이 없으면 그 식을 믿을 수 있음.
4. 여러 변수로 하나를 설명하려면 **소프트센서** (다변수 회귀).

### 주의할 점
- 한 변수의 상관은 다른 변수의 영향을 무시합니다. 공통 원인이 의심되면 상관계수 종류를 **편상관** 으로.
- 실험 조건을 동시에 바꾼 변수끼리는 효과를 구분할 수 없습니다 (VIF 확인).
