# 품질 이상 원인 찾기 (분석값 중심)

**목적**: 분석값(조성·물성)이 규격을 벗어나거나 흔들릴 때, 어떤 운전 변수가 먼저 움직였는지 찾습니다.

### 준비할 데이터
| 구분 | 내용 |
|---|---|
| ② 분석데이터 | 분석시간 + 항목별 값 (예: `Component 1, 2, 3`). 이상이 있었던 기간과 정상 기간이 **함께** 들어가야 비교할 수 있음 |
| ① 운전데이터 | 그 공정단위의 주요 유량·온도·압력·조작 변수. 분석값보다 **몇 시간 앞선 기간부터** |

### 분석 순서
1. **트렌드**: `[분석]` 항목을 고르면 점으로 표시됩니다. 튄 시점을 확인하고, 주변 운전 변수를 태그별 분리로 비교.
2. **상관분석 → 변수 쌍 순위**: 변수로 거르기 = 문제 항목. **결과 요약** 의 상위 변수가 1차 후보.
3. **시차 상관**: 후보 변수 → 분석값. 봉우리가 양수 쪽이면 그 변수가 먼저 움직임 = 원인 후보 강화.
4. **운전 구간별 비교**: 이상 기간과 정상 기간을 변화점(또는 상태 컬럼)으로 나눠, 구간별 평균이 크게 다른 운전 변수를 확인.
5. **이상감지 (PCA)**: 정상 기간으로 학습 → 이상 시점의 **기여도** 상위 태그.
6. 후보가 정해지면 **소프트센서** 로 분석값을 예측해 보고, 잔차 알람으로 이후 재발을 감시.

### 주의할 점
- 분석값이 적으면(수십 건) 상관이 우연히 크게 나올 수 있습니다. p값과 산점도를 함께 보세요.
- 분석값은 분석시간 기준이라 원인보다 늦게 찍힙니다. 시차 상관의 양수 지연이 자연스럽습니다.
- 계기 이상(값 고착·튀는 값)이 원인처럼 보일 수 있습니다. 트렌드로 먼저 확인하세요.
