# 증류탑

**목적**: 제품 조성(순도·불순물)이 무엇에 따라 변하는지 찾고, 조성을 실시간으로 추정하거나 에너지(스팀)를 줄일 여지를 찾습니다.

### 준비할 데이터
| 구분 | 태그 |
|---|---|
| 결과 (Y) | **분석데이터**: 탑정·탑저 제품 조성 (예: `Component 1, 2, 3`) |
| 원인 후보 (X) — 필수 | 원료 유량, 환류량(또는 환류비), 리보일러 스팀량(열량), **감도 트레이 온도**(조성과 가장 연관된 트레이), 탑정·탑저 온도, 탑압력 |
| 있으면 좋음 | 원료 온도·조성, 탑정·탑저 제품 유량, 차압(ΔP), 응축기 냉각수 온도 |

### 먼저 볼 관계
| 관계 | 확인할 것 | 어디서 |
|---|---|---|
| 감도 트레이 온도 ↔ 제품 조성 | 가장 강해야 정상. 약하면 온도 제어 기준 트레이 위치를 재검토 | 상관분석 → 변수 쌍 순위 |
| 환류비(환류량 ÷ 제품량) ↔ 탑정 조성 | 곡선 관계가 흔함: 올려도 순도가 더 안 오르는 지점부터는 스팀 낭비 | 이변량 회귀 (2차 다항식) |
| 스팀량 ÷ 원료량 ↔ 탑저 조성 | 에너지 원단위와 품질의 균형점 | 이변량 회귀 |
| 차압 ↔ 원료량·스팀량 | 차압이 부하에 비해 갑자기 커지면 범람(flooding)·오염 징후 | 트렌드, 운전 구간별 비교 |
| 탑압력 ↔ 트레이 온도 | 압력이 바뀌면 같은 조성에서도 온도가 바뀜 → 온도 제어에 압력 보정 필요 여부 | 운전 구간별 비교 (압력으로 구간 나누기) |

### 분석 순서
1. **트렌드**: 조성 분석값과 감도 트레이 온도를 **태그별 분리** 로 나란히 — 같이 움직이는지 눈으로 확인.
2. **상관분석 → 변수 쌍 순위**: 변수로 거르기 = 조성 분석값. 결과 요약의 상위 변수를 확인.
3. **시차 상관**: X = 감도 트레이 온도, Y = 조성 → 분석값이 몇 분 늦게 반응하는지 (분석시간 기준이라 보통 30분~수 시간).
4. **소프트센서**: 예측 대상 = 조성, 입력 = 감도 트레이 온도·환류량·스팀량·원료량·탑압력, **최적 지연 자동 탐색**.
5. **운전 구간별 비교**: 부하·압력이 다른 기간이 섞였다면 구간을 나눠 관계가 같은지 확인.

### 주의할 점
- 온도를 PID로 일정하게 제어하면 온도가 거의 안 움직여 상관이 작게 나옵니다. 이때는 **조작 변수(환류량·스팀량)** 와의 관계를 보세요.
- 분석값은 **분석시간** 기준이라 실제 공정 상태보다 늦습니다. 지연 탐색·시차 상관으로 보정하세요.
- 원료 조성이 바뀐 기간은 관계가 달라질 수 있습니다 (운전 구간별 비교).
