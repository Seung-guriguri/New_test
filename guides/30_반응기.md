# 반응기

**목적**: 촉매 활성이 얼마나 빨리 떨어지는지(WABT 상승 속도), 운전 말기(EOR)가 언제인지, 전환율·선택도가 무엇에 따라 변하는지 봅니다.

### 준비할 데이터
| 구분 | 태그 |
|---|---|
| 필수 | 촉매층별 입구·출구 온도 (층별 촉매량 비율은 직접 입력) |
| 성능 (있으면) | 원료 유량, 반응물 입·출구 분율, 생성물 출구 분율 — 또는 **분석데이터** 의 조성 |
| 있으면 좋음 | 반응기 압력, 수소(또는 공반응물) 유량·비, 원료 성상, 촉매 교체·재생 이력 |

### 먼저 볼 관계
| 관계 | 확인할 것 | 어디서 |
|---|---|---|
| WABT 시간 추세 | 상승 속도(℃/일) = 촉매 활성 저하 속도, EOR 도달 예상일 | 설비 KPI → 반응기 |
| 층별 발열 ΔT | 한 층만 줄면 그 층 촉매 문제·편류 의심 | 설비 KPI → 반응기 |
| WABT ↔ 전환율(또는 제품 조성) | 같은 전환율을 내는 데 필요한 온도가 오르는지 | 이변량 회귀 |
| 원료 유량(LHSV) ↔ 전환율 | 부하를 올리면 전환율이 얼마나 떨어지는지 | 상관분석 → 이변량 회귀 |
| 최고 온도 ↔ 원료·유량 | 핫스팟이 어떤 조건에서 생기는지 | 트렌드, 운전 구간별 비교 |

### 분석 순서
1. **설비 KPI → 반응기**: 촉매층 표 입력, EOR 한계 입력 → WABT 추세·EOR 날짜.
2. **상관분석 → 변수 쌍 순위**: 변수로 거르기 = `[RX] 전환율 [%]` 또는 제품 조성 분석값.
3. **소프트센서**: 예측 대상 = 전환율(또는 조성), 입력 = WABT·원료 유량·압력 등.
4. **변화점 탐지**: `[RX] WABT` → 촉매 교체·운전 변경 시점.

### 주의할 점
- 유량과 분율은 같은 기준(몰 또는 질량)이어야 전환율·선택도가 맞습니다.
- 원료 성상이 바뀌면 WABT 상승 속도도 바뀝니다. 구간을 나눠 보세요.
